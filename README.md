## Setup lần đầu (làm 1 lần)

### Bước 1 — Cài Google Drive for Desktop
→ [Tải tại đây](https://www.google.com/drive/download/)
→ Đăng nhập bằng tài khoản Google

### Bước 2 — Nhận quyền truy cập folder
→ Minh Thư sẽ share link Google Drive folder với bạn
→ Vào Google Drive → tìm thư mục "MekongTESOL2026-Team" trong mục **Shared with me**
→ Chuột phải → **Add shortcut to My Drive** (thêm vào My Drive)

### Bước 3 — Sync về máy
→ Mở **Google Drive for Desktop**
→ Vào Settings → chọn sync folder "MekongTESOL2026-Team"
→ Folder sẽ xuất hiện trong Finder/Explorer trên máy bạn

### Bước 4 — Mở trong Antigravity
→ Mở Antigravity
→ Chọn **Open Project** (hoặc New Project → Browse)
→ Trỏ đến folder `MekongTESOL2026-Team` trên máy bạn
→ Antigravity sẽ tự đọc skill `.agents/skills/mekong-tesol-content/`

**Xong!** Bây giờ bạn đã có đầy đủ skill + knowledge giống các thành viên khác.

## Cách làm việc hằng ngày

### Nhận update từ team
→ Google Drive tự sync → **không cần làm gì thêm**
→ Khi có file mới hoặc skill được cập nhật, máy bạn sẽ tự nhận trong vài phút

### Tạo email / nội dung mới
1. Mở Antigravity với project `MekongTESOL2026-Team`
2. Gõ yêu cầu bình thường: *"viết email nhắc nhở presenter 1 tuần trước hội thảo"*
3. AI tự dùng skill + brand system + knowledge base
4. Lưu file vào **`workspace/[tên bạn]/`** — không lưu đè vào `templates/`

### Dùng template có sẵn
→ Mở folder `templates/`
→ Copy file cần dùng vào `workspace/[tên bạn]/`
→ Chỉnh nội dung, không xóa file gốc
